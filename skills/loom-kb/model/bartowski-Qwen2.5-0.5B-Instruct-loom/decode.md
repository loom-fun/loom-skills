# Qwen2.5 0.5B: decode attention masks

Measured on SDK 0.2.0, 2026-11-17, for this package's ordinary paged hd64 split kernel.

- **Instruction counts alone did not predict a gain.** Replacing the two interval comparisons with one unsigned comparison reduced the gfx1201 whole-kernel static count from 941 to 821, but the full-size isolated attention case was 1.303 ms legacy versus 1.301 ms unsigned (-0.1%). Keep the direct-only form out of the production choice API.
- **Bypassing masks on fully visible blocks helped the kernel.** A uniform branch skips per-key mask comparisons/selects on aligned interior blocks; edge blocks retain the unsigned interval test and all floating arithmetic keeps its order. Five interleaved repetitions over all 24 layers of a 384 MiB KV arena measured 1.303 ms legacy [1.294–1.311] versus 1.217 ms full-block [1.213–1.221], a 6.6% isolated kernel reduction. All 13 exact boundary/reference cases passed, including a nonzero analytic reference. [Kernel evidence](https://github.com/loom-fun/loom-skills/actions/runs/44170614219).
- **Model performance remained within the noise band.** The latest two independent R9700 ABBA comparisons used six sessions and three samples per fast row: decode_32k ratios 1.0272 and 1.0217, with every row passing the unchanged mode guard and promotion ratchet. These are non-regression results, not an above-noise model-speedup claim. An earlier 1.0416 ratio was mode-flagged and does not count as a confirmed gain. [First pair](https://github.com/loom-fun/loom-skills/actions/runs/44172014122), [bounded confirmation](https://github.com/loom-fun/loom-skills/actions/runs/44175206518).
- **Scope matters.** Only the R9700 twin is eligible for `decode.attn.full_blocks`; its default is false. The Strix results had mode-frequency flags, so Strix kernels retain their legacy bodies. Listed prefill, GQA, multi-token and segment masks also keep their old behavior. Measure before expanding to another shape or GPU family.

For ordered unsigned bounds `0 <= lo <= hi < 2**W`, `(key - lo) mod 2**W < hi - lo` is equivalent to `lo <= key < hi`: below-lo subtraction wraps above the interval width, above-hi subtraction is at least the width, and an empty interval has width zero. The SDK backend's actual modular subtract/unsigned-compare lowering was inspected. The serving domain is far below either 32-bit or 64-bit wrap limit. Reversed inactive-span bounds do not satisfy this identity's precondition and remain on the legacy mask path.
